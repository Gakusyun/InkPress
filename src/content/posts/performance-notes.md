个人博客的瓶颈通常不在框架，而在：

1. 首屏阻塞资源
2. 过大的图片与字体
3. 每页塞进无关脚本

## 本框架的选择

- 系统字体栈，默认不下载 Web Font
- CSS 随页加载，构建期压缩
- 搜索索引在打开弹层时再 `fetch`，不内联进每页 HTML
- 代码高亮在构建期完成（Shiki），客户端零 JS 高亮

## 你可以继续做的

```bash
pnpm build
```

看 `dist/` 体积；文章变多后，优先压缩图片，而不是先上懒加载框架。

## 结论

对静态博客：**少即是快**。把交互留在读者真正会用到的那一刻（搜索、设置）。
