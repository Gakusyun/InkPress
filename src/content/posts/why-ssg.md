边缘运行时渲染很灵活，但对博客来说，**预渲染静态 HTML** 往往更合适：

- CDN 缓存命中简单
- 无冷启动
- 攻击面更小
- 构建失败不会影响线上旧文

动态能力（搜索、评论）可以放在客户端或可选集成，而不必把整站绑在 Worker 上。

```ts
// 搜索在浏览器过滤构建时生成的索引
const hits = docs.filter((d) => d.title.includes(q));
```
